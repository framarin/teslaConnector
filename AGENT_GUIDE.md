# Come posso aiutarti come Agente di Sviluppo Flutter

## 🤖 Capacità dell'Agente per Flutter Development in VSCode

### 📱 Sviluppo Flutter Assistito

Come agente AI specializzato in Flutter, posso aiutarti in diversi modi:

#### 1. **Generazione e Refactoring del Codice**
- Creare widget personalizzati e screen completi
- Implementare pattern architetturali (BLoC, Provider, Riverpod)
- Generare modelli di dati con serializzazione JSON
- Refactoring automatico per migliorare la performance

#### 2. **Debugging e Risoluzione Problemi**
- Analizzare stack trace e errori di runtime
- Identificare memory leak e problemi di performance
- Suggerire soluzioni per errori di build
- Ottimizzazione del codice per diverse piattaforme

#### 3. **Testing Automatizzato**
- Creare test unitari per widget e servizi
- Implementare test di integrazione
- Configurare test automatici con GitHub Actions
- Generare mock e test data

#### 4. **Configurazione Ambiente di Sviluppo**
- Setup ottimizzato per VSCode con Flutter
- Configurazione di linter e formatter
- Gestione delle dipendenze e versioning
- CI/CD pipeline per deployment automatico

### 🚀 Workflow di Sviluppo Suggerito

#### **1. Sviluppo Iterativo**
```bash
# Avvia in modalità debug con hot reload
flutter run --debug

# In parallelo, esegui i test automaticamente
flutter test --watch
```

#### **2. Code Review Automatico**
```bash
# Analisi statica del codice
flutter analyze

# Formatting automatico
dart format .
```

#### **3. Testing Continuo**
```bash
# Test unitari
flutter test

# Test di integrazione
flutter test integration_test/
```
